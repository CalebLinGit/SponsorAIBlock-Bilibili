# SponsorAIBlock 使用教程

AI 驱动的 B 站恰饭广告智能跳过插件。

---

## 一、安装

### 1. 下载插件

从 Release 页面下载最新版本的 `sponsoraiblock.zip`，解压到本地任意文件夹。

[截图占位 — 1：Release 页面下载截图]

### 2. 加载到 Chrome

1. 打开 Chrome，地址栏输入 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」，选择解压后的文件夹

[截图占位 — 2：Chrome 扩展管理页，开发者模式开启 + 加载未打包按钮]

安装成功后，浏览器右上角会出现插件图标。

[截图占位 — 3：Chrome 工具栏中的插件图标]

---

## 二、配置 API 密钥

本插件使用 Google Gemini AI 进行广告识别，需要自行申请免费 API 密钥。

### 1. 获取 Gemini API 密钥

前往 [Google AI Studio](https://aistudio.google.com/apikey) 申请密钥，免费额度足够日常使用。

[截图占位 — 4：Google AI Studio 密钥申请页面]

### 2. 填入插件

1. 点击 Chrome 工具栏中的插件图标，打开配置面板
2. 在「AI 配置」区域，将密钥粘贴到「API 密钥」输入框
3. 点击「保存」，刷新 B 站页面生效

[截图占位 — 5：插件弹窗 — AI 配置区域，密钥已填入]

## 三、各配置项说明

点击插件图标打开配置面板，切换到「配置」标签。

[截图占位 — 6：完整配置面板截图]

### 基本配置

| 配置项 | 说明 |
|---|---|
| 忽略小于 5 分钟的视频 | 开启后，短视频不会触发 AI 识别，节省 API 用量 |

### AI 配置

| 配置项 | 说明 |
|---|---|
| AI 模型 | 推荐使用 `gemini-2.5-flash`（速度快、免费额度高）；`gemini-2.5-pro` 精度更高但消耗更多配额 |
| API 密钥 | 填入从 Google AI Studio 获取的密钥 |

### 弹幕兜底

| 配置项 | 说明 |
|---|---|
| 无字幕时使用弹幕兜底 | 当视频没有字幕，但雷达检测到疑似广告时，自动拉取弹幕作为 AI 输入。弹幕识别精度略低于字幕 |

### 雷达检测

雷达是 AI 之前的前置检测层，可在不消耗 AI 配额的情况下识别明显广告。

| 配置项 | 说明 |
|---|---|
| 启用雷达预检测 | 建议始终开启。关闭后所有识别都依赖 AI |
| 硬广处理方式 | 对「插播广告」（话题突然切换的独立广告段）的处理方式：自动跳过 / 提示用户 / 忽略 |
| 深度植入广告处理方式 | 对「深度植入」（产品融入视频内容超过 30%）的处理方式：自动跳过 / 提示用户 / 忽略 |
| 置信度阈值 | AI 识别结果的最低置信度（0~1）。低于此值时不会自动跳过，会改为提示用户。推荐 0.6 |

## 四、工作原理

```
B 站播放页加载
  → XHR 拦截（api.bilibili.com/x/player/wbi/v2）
  → 缓存检查（同一视频 3 天内不重复识别）
  → 雷达预检测
      ├─ 章节关键词命中（好东西 / 福利 / 老朋友 / 恰饭）→ 直接标记，无需 AI
      ├─ 商品链接检测（评论区固定商品卡）
      └─ 标签冲突检测
  → 字幕获取
      └─ 无字幕 + 雷达命中 → 弹幕兜底
  → Gemini AI 分析
  → 进度条标红 + 自动跳过 / 提示
```

**广告类型说明：**

- **硬广（Hard_Ad）**：视频中途插入与主题无关的广告段，通常有明显的话题切换。插件会在进度条上标红，并根据设置自动跳过或提示。
- **深度植入（Integrated_Ad）**：产品深度融入视频内容（如开着某品牌车测评、用某产品完成核心任务）。此类广告不建议自动跳过，默认设置为「提示用户」。

## 五、常见问题

**Q：打开视频后进度条没有标红？**

- 确认视频时长大于 5 分钟（如开启了「忽略小于 5 分钟的视频」）
- 确认 API 密钥已正确填写并保存
- 确认已登录 B 站
- 视频可能没有广告，或广告未被识别（字幕缺失且弹幕兜底未开启）

[截图占位 — 7：进度条标红示例]

**Q：提示「无字幕，跳过识别」？**

该视频没有 CC 字幕，且雷达未检测到明显广告信号，插件跳过了 AI 分析。  
可尝试开启「无字幕时使用弹幕兜底」。

**Q：识别结果不准确（误跳 / 漏跳）？**

- 将「置信度阈值」提高（减少误跳）或降低（减少漏跳）
- 对于深度植入广告，建议使用「提示用户」而非「自动跳过」
- 识别依赖字幕质量，官方字幕效果优于 AI 生成字幕

**Q：API 配额会用完吗？**

Gemini 免费额度每分钟 15 次请求，每天 1500 次，日常使用基本够用。  
每个视频只识别一次（结果缓存 3 天），重复播放不消耗配额。

**Q：如何查看识别日志？**

打开 Chrome 开发者工具（F12）→ Console 面板，搜索 `[SAI` 可看到完整识别过程。
